## Где что

- **Репозиторий:** `norin-web/Task-boart-hsym` (GitHub). Сайт: https://norin-web.github.io/Task-boart-hsym/ — деплой GitHub Actions при push в `main`.

### Выкатка на прод — строго по порядку

Если обновить только базу, текущий сайт закроет доступ всем; если только фронт — новый фронт не заработает со старой базой.

1. Supabase → SQL Editor: выполнить `supabase/schema.sql` целиком (идемпотентный, можно повторять).
2. Сразу там же назначить супер-админа:
   ```sql
   update people set access = 'superadmin', active = true where lower(email) = 'norinnort4@gmail.com';
   ```
3. Edge Functions → Deploy new function → Via Editor, имя `admin-users`, код из `supabase/functions/admin-users/index.ts`, Verify JWT включён.
4. Слить изменения в `main` → GitHub Actions задеплоит сайт.
5. Проверить вход супер-админом, затем в «Люди и доступы» выдать позиции участникам.

## Как работать

```bash
npm install
npm run dev      # http://localhost:5177 — без .env.local это локальный режим (Postgres в браузере)
npm test         # тесты логики и прав на настоящем Postgres (PGlite) со схемой из supabase/schema.sql
npm run build
```

- Локальный режим: «Заполнить демо-данными» на пустой главной; проверка ролей — меню профиля → «Войти как…».
- Вся бизнес-логика — `web/src/backend.js` (тот же код работает с Supabase и PGlite). Новая логика → тест в `test/`.
- Схема — только идемпотентные изменения в `supabase/schema.sql` (`add column if not exists` и т.п.).
- Права — в базе (RLS/триггеры), интерфейс только прячет недоступное.
- Коммиты — по-русски, коротко; без подписей ИИ / Co-Authored-By.

## Принципы интерфейса (от заказчика)

- Не уводить пользователя: задачи открываются поверх, мелкие правки — прямо в строке.
- Без «мельтешения»: никаких раскрывающихся панелей, которые прыгают; стабильные списки, плавные изменения.
- Админ тоже выполняет задачи: статистика задач и «Требует внимания» — важны, не убирать.
- Блоки главной должны нормально жить и в широкой, и в узкой колонке (container queries; у grid-контейнеров `grid-template-columns: minmax(0, 1fr)`).
