# Опись RM: что есть в коде и что есть на листах

Собрано 2 ноября 2026: код, снимки за Сергея Волкова (RM01–RM08), поиск по файлу Paper. Порядок: код, дизайн, рисунок, аппрув владельца, перенос.

## Есть лист
- Дашборд RM: лист 32 на странице Tasks DS, старый (логотип HSYM, без колокольчика, другой сайдбар)
- Карточка релиза B08, B09, форма реджекта и закрытие реджекта P31, ход релиза 56т (тёмный)
- Настройки «Релизы» 54т (тёмный), меню P38–P39, окна P30–P37, состояния P40–P41

## Пакет 1. Дашборд RM
- [ ] Очередь на релиз: не заполнено, готово к отправке, реджект исправлен, «Показать ещё»
- [ ] На ревью Apple, Реджекты, Релизы в App Store, блок «Отслеживаю», пустые варианты
- [ ] Длинное название приложения: сейчас обрезается многоточием

## Пакет 2. Карточка релиза глазами RM
- [ ] Все этапы: подготовка, ревью, реджект, вышло, правка полей, чеклист
- [ ] Опросник разработчика: длинные вопросы складываются в узкую колонку
- [ ] Боковая колонка: вид исполнителя и приоритета только для чтения

## Пакет 3. Окна RM
- [ ] История релизов, Настройка релиза, Настроить карточку релиза, Отслеживать на дашборде, правка релизного поля

## Пакет 4. Общие экраны, вид RM
- [ ] Приложения, Моя доска, юнит и его вкладки, настройки «Релизы»

## Пакет 5. Состояния RM
- [ ] Пустые, загрузка, только чтение, ошибки на экранах выше

## Расхождения, нужны решения владельца
1. На листе 32 в очереди есть «от Екатерины», в коде подпись PM не выводится.
2. В коде у неготового релиза кнопка «Открыть релиз», на листе её нет.
3. Лист: «Мои юниты» только с юнитами RM. В коде RM видит все юниты, включая Gold, где его нет.
4. «Мои задачи» есть как экран, но в сайдбаре RM ссылки нет. Задачи RM доступны только через «Мою доску».
5. На листе у RM нет колокольчика, в коде он есть.
